File formats#

This page lists the formats Larmor reads and writes, with the Python functions for each. The load_ and save_ functions of larmor.io, and the lar commands, choose the format from the end of the file name. The read_ and write_ functions of larmor.io.formats each read or write one format.

Registrations#

Larmor reads transforms but does not write them. load_transform() works out the format from the file where it can. It reads a text .mat file as a FLIRT matrix, and a text file with MRtrix3’s # command_history: comment, or with 3 rows of 4 numbers, as an MRtrix3 transform. Any other 4x4 text matrix could be either, and the two map different coordinates, so you must give the format: format="fsl" or "mrtrix" in Python, --format on the command line.
