class larmor.sd.DRL(*, num_iter=200, hr_num_iter=600, target_adc=0.0007, nu_scale=0.2)#

Damped Richardson-Lucy (dRL) deconvolution, an FOD solver for SDModel.

It is the default solver of the GRL method. The FOD stays non-negative. The damping slows the update of directions whose amplitude is below a threshold nu, so that the isotropic background does not grow into spurious peaks; nu is nu_scale times the largest FOD amplitude that an undamped deconvolution gives for a purely isotropic tissue of diffusivity target_adc. A voxel stops early when its FOD no longer changes.

num_iter#

Maximum number of iterations of a single-tissue fit, and of each FOD solve in the loop that alternates FOD and tissue-fraction fits in a multi-tissue fit. Defaults to 200.

Type:

int

hr_num_iter#

Maximum number of iterations of the final FOD solve of a multi-tissue fit. Defaults to 600.

Type:

int

target_adc#

Diffusivity in mm^2/s of the isotropic tissue nu is set from. Defaults to 0.7e-3.

Type:

float

nu_scale#

Fraction of that tissue’s largest FOD amplitude that becomes nu. Defaults to 0.2.

Type:

float

References

Dell’Acqua F, Scifo P, Rizzo G, et al. A modified damped Richardson-Lucy algorithm to reduce isotropic background effects in spherical deconvolution. NeuroImage 49 (2010) 1446-1458. doi:10.1016/j.neuroimage.2009.09.033

Follows MRIToolkit’s implementation (MRTTrack).

class larmor.sd.L2NNLS(*, reg=0.1, tol_x=1e-06)#

Non-negative least squares (NNLS) with a ridge (L2) penalty, an FOD solver.

It is the default solver of the mFOD method. With K the kernel (the signals of the response functions along the FOD directions) and s a voxel’s signal, the FOD f minimises ||K f - s||^2 + reg^2 ||f||^2 subject to f >= 0. In a multi-tissue fit, the FOD solves of the loop that alternates FOD and tissue-fraction fits use plain NNLS (reg 0); the final solve, and the only solve of a single-tissue fit, use the penalty.

reg#

Weight of the penalty; 0 gives plain NNLS. Defaults to 0.1.

Type:

float

tol_x#

A coefficient enters the solution only when its gradient exceeds this. Defaults to 1e-6.

Type:

float

References

De Luca A, Guo F, Froeling M, Leemans A. Spherical deconvolution with tissue-specific response functions and multi-shell diffusion MRI to estimate multiple fiber orientation distributions (mFODs). NeuroImage 222 (2020) 117206. doi:10.1016/j.neuroimage.2020.117206

Lawson CL, Hanson RJ. Solving Least Squares Problems. Prentice-Hall, 1974.

Follows MRIToolkit’s L2LSQ method (MRTTrack).

class larmor.sd.Lasso(*, reg=0.01, alpha=0.9, tol=0.0001, max_iter=100000)#

Elastic-net (LASSO-type) regression of the signal, an FOD solver.

The signal s is regressed, without an intercept, on the columns of the kernel, the signals of the response functions along the FOD directions, each scaled to unit root mean square (K0). With m measurements, the coefficients b minimise (1 / 2m) ||s - K0 b||^2 + reg (alpha ||b||_1 + (1 - alpha) / 2 ||b||^2), and the FOD is b divided by the column scales. In a multi-tissue fit, s is the signal left after the isotropic tissues are subtracted. Every FOD solve of a fit uses the same penalty.

The FOD is not constrained to be non-negative. In a multi-tissue fit, FOD values below their median are set to zero before the tissue fractions are fitted, but the FOD itself keeps its negative values. When reg is large enough that no direction explains enough of the signal, the FOD is zero.

reg#

Overall weight of the penalty, lambda. Defaults to 0.01.

Type:

float

alpha#

Share of the penalty on the L1 norm, in (0, 1]; 1 is the plain LASSO. Defaults to 0.9.

Type:

float

tol#

Coordinate descent stops when no coefficient changes by more than this, relative to 1 + its size, over a sweep. Defaults to 1e-4.

Type:

float

max_iter#

Maximum number of sweeps over the columns. A solve that reaches it without converging keeps its last sweep, and the fit warns how many solves did. Defaults to 100_000.

Type:

int

References

Tibshirani R. Regression shrinkage and selection via the lasso. J R Stat Soc B 58 (1996) 267-288.

Zou H, Hastie T. Regularization and variable selection via the elastic net. J R Stat Soc B 67 (2005) 301-320. doi:10.1111/j.1467-9868.2005.00503.x

The method follows MRIToolkit’s LASSO method (MRTTrack, version 1.8), whose default Alpha is 0.9.

class larmor.sd.AnisotropicRF(eigen_vals, mean_kurtosis, *, signal_offset=0.0)#

Response of a single fibre, a diffusion tensor with an isotropic kurtosis term.

The signal along gradient g at b-value b is exp(-b g^T D g + b^2 MD^2 K / 6) + offset, with D the tensor turned so that its first eigenvector points along the fibre, MD its mean eigenvalue and K the mean kurtosis.

mean_kurtosis#

Mean kurtosis K, dimensionless.

Type:

float

signal_offset#

Constant added to the signal, which is otherwise 1 at b = 0. Defaults to 0.

Type:

float

References

Jensen JH, Helpern JA, Ramani A, Lu H, Kaczynski K. Diffusional kurtosis imaging: the quantification of non-Gaussian water diffusion by means of magnetic resonance imaging. Magn Reson Med 53 (2005) 1432-1440. doi:10.1002/mrm.20508

The kernel follows MRIToolkit’s (MRTTrack).

class larmor.sd.CSDModel(response=None, *, solver=None, lmax=8, basis='tournier')#

Constrained spherical deconvolution (CSD) of one shell into an FOD.

The fit uses the shell with the highest b-value and leaves out the others, b0s included. Each voxel’s signal on that shell is fitted as it is, in the response’s units (not divided by b0), so the FOD’s integral (c00 sqrt(4 pi)) is the voxel’s signal relative to the response’s. Negative signal values are fitted as 0. lmax is kept as given, even with more SH coefficients than the shell has directions. FODs come out in the frame of the DWI’s b-vectors.

References

Tournier JD, Calamante F, Connelly A. Robust determination of the fibre orientation distribution in diffusion MRI: non-negativity constrained super-resolved spherical deconvolution. NeuroImage 35 (2007) 1459-1472. doi:10.1016/j.neuroimage.2007.02.016

The defaults follow MRtrix3’s dwi2fod csd: Tournier JD, Smith R, Raffelt D, et al. MRtrix3: A fast, flexible and open software framework for medical image processing and visualisation. NeuroImage 202 (2019) 116137. doi:10.1016/j.neuroimage.2019.116137

class larmor.sd.CSDSolver(*, neg_lambda=1.0, norm_lambda=1.0, threshold=0.0, max_iter=50, init_lmax=4, directions=None)#

The settings of constrained spherical deconvolution (CSD), for CSDModel.

Each voxel’s FOD starts from a linear deconvolution up to init_lmax. Each iteration then penalises the FOD on the constraint directions where it is below the threshold, until that set of directions repeats. Both penalties are scaled by the response, so their strength does not depend on the signal’s units.

threshold#

Type:

float

max_iter#

Maximum number of constrained solves per voxel; 0 gives the linear estimate. Defaults to 50.

Type:

int

init_lmax#

Highest degree of the linear estimate the iterations start from. Defaults to 4.

Type:

int

directions#

Unit vectors the constraint is applied on, shape (n, 3). Defaults to None, Larmor’s built-in set of 300 directions.

Type:

numpy.ndarray | None

class larmor.sd.MSMTCSDModel(rfs=None, *, lmax=8, basis='tournier', directions=None, progress=False)#

Multi-shell multi-tissue constrained spherical deconvolution (MSMT-CSD).

Each tissue has a response given by its zonal SH coefficients on every shell (a ZonalSHRF, in the format MRtrix3’s dwi2response writes). A response with lmax above 0 gives an FOD, and one with lmax 0 an isotropic tissue. In each voxel, all tissues are fitted at once to every measurement, b = 0 included, with their FOD amplitudes and isotropic coefficients kept non-negative. The signal is fitted as measured, not divided by S0, so an FOD’s integral, c00 sqrt(4 pi), is its tissue’s share of the signal relative to the response. The least squares has a ridge of 1e-10 times the largest diagonal entry of the normal matrix. b-values are in s/mm^2; FODs come out in the frame of the DWI’s b-vectors.

References

Jeurissen B, Tournier JD, Dhollander T, Connelly A, Sijbers J. Multi-tissue constrained spherical deconvolution for improved analysis of multi-shell diffusion MRI data. NeuroImage 103 (2014) 411-426. doi:10.1016/j.neuroimage.2014.07.061

The defaults (lmax 8 or the response’s, all shells weighted equally, the ridge) follow MRtrix3’s dwi2fod msmt_csd: Tournier JD, Smith R, Raffelt D, et al. MRtrix3: A fast, flexible and open software framework for medical image processing and visualisation. NeuroImage 202 (2019) 116137. doi:10.1016/j.neuroimage.2019.116137

Lawson CL, Hanson RJ. Solving Least Squares Problems. Prentice-Hall, 1974 (chapter 23, least squares with inequality constraints).

class larmor.sd.NoddiRF(*, intra_fraction=0.4, parallel_diffusivity=0.0017, concentration=1.0, iso_fraction=0.0, iso_diffusivity=0.003, s0=1.0)#

Response of the NODDI model of dispersed neurites and free water.

The neurites are sticks with diffusivity d along them and none across, their orientations spread around the response’s axis by a Watson distribution of concentration kappa. The space around them is a tensor with the same parallel diffusivity and d (1 - f_in) across, averaged over the same distribution. The signal is accurate to about 1e-7 or better for kappa between 0.3 and 30 and for b d = 0 or above 0.2; near kappa 0.1 and b d 0.05, and above kappa 30, the high-degree terms lose precision.

Type:

float

concentration#

Watson concentration kappa; larger is less dispersed.

Type:

float

iso_fraction#

Volume fraction of free water, f_iso.

Type:

float

iso_diffusivity#

Diffusivity of free water d_iso, in mm^2/s.

Type:

float

s0#

Signal at b = 0.

Type:

float

References

Zhang H, Schneider T, Wheeler-Kingshott CA, Alexander DC. NODDI: practical in vivo neurite orientation dispersion and density imaging of the human brain. NeuroImage 61 (2012) 1000-1016. doi:10.1016/j.neuroimage.2012.03.072

class larmor.sd.SDModel(rfs, *, method=SDMethod.GRL, solver=None, inner_shell_weight=None, lmax=8, basis='tournier', progress=False)#

Spherical deconvolution of DWI data into FODs with the GRL or mFOD method.

With a single anisotropic response function and no isotropic one, the fit is single-tissue, one FOD solve per voxel. Otherwise it is multi-tissue, and each voxel alternates between fitting the FODs and the tissue fractions until the fractions settle. b-values are in s/mm^2 and the response functions’ diffusivities in mm^2/s. FODs come out in the frame of the DWI’s b-vectors.

References

GRL: Guo F, Leemans A, Viergever MA, Dell’Acqua F, De Luca A. Generalized Richardson-Lucy (GRL) for analyzing multi-shell diffusion MRI data. NeuroImage 218 (2020) 116948. doi:10.1016/j.neuroimage.2020.116948

mFOD: De Luca A, Guo F, Froeling M, Leemans A. Spherical deconvolution with tissue-specific response functions and multi-shell diffusion MRI to estimate multiple fiber orientation distributions (mFODs). NeuroImage 222 (2020) 117206. doi:10.1016/j.neuroimage.2020.117206

The solvers (dRL, L2NNLS, LASSO) cite their own papers: see larmor.sd.DRL, larmor.sd.L2NNLS and larmor.sd.Lasso.

class larmor.sd.SDFit(fods, tissue_fractions, basis, lmax, peak_relative_threshold=0.1)#

Result of a spherical deconvolution fit.

(X, Y, Z) is the spatial shape of the DWI and N the number of response functions. The FODs have even degrees only, so they have C = (lmax + 1)(lmax + 2) / 2 spherical harmonic (SH) coefficients, 28 for lmax 6.

One FOD per anisotropic response function, in the order given to the model, each as SH coefficients in basis, shape (X, Y, Z, C), zero outside the mask. With the L2NNLS and Lasso solvers, c00 is set to the sum of the FOD’s values on the fit’s directions divided by sqrt(4 pi), so that its integral over the sphere is exact.

Type:

list[numpy.ndarray]

tissue_fractions#

Fraction of each response function per voxel, shape (X, Y, Z, N), summing to 1 inside the mask. The anisotropic response functions come first, then the isotropic ones, each group in the order given to SDModel. None for a single-tissue fit (one anisotropic response function and no isotropic one).

Type:

numpy.ndarray | None

basis#

SH basis of the FODs, “tournier” (MRtrix, readable by mrview), “leemans” (ExploreDTI and MRIToolkit) or “descoteaux”.

Type:

str

lmax#

Maximum SH degree actually used. It can be lower than the lmax given to the model when the highest shell has too few directions.

Type:

int

peak_relative_threshold#

The relative threshold to give find_peaks for these FODs; 0.2 for the FODs of SDModel, whose truncation to lmax leaves side lobes where fibres cross, and 0.1 for CSD and MSMT-CSD.

Type:

float

class larmor.sd.SDMethod#

Spherical deconvolution methods.

GRL fits one anisotropic response function (white matter) and any number of isotropic ones (such as grey matter and CSF); its FOD solver is damped Richardson-Lucy and its inner shells are weighted 0.2. mFOD fits one or more anisotropic response functions, one FOD each, with all shells weighted equally; its FOD solver is L2-regularised NNLS.

References

GRL: Guo F, Leemans A, Viergever MA, Dell’Acqua F, De Luca A. Generalized Richardson-Lucy (GRL) for analyzing multi-shell diffusion MRI data. NeuroImage 218 (2020) 116948. doi:10.1016/j.neuroimage.2020.116948

mFOD: De Luca A, Guo F, Froeling M, Leemans A. Spherical deconvolution with tissue-specific response functions and multi-shell diffusion MRI to estimate multiple fiber orientation distributions (mFODs). NeuroImage 222 (2020) 117206. doi:10.1016/j.neuroimage.2020.117206

Both follow MRIToolkit’s implementation (MRTTrack).

MFOD = 'mFOD'#

class larmor.sd.ZonalSHRF(*, bvals, coefficients)#

Response given by its zonal spherical harmonic coefficients on each shell.

On a shell of b-value b, the signal along a gradient at angle t to the response’s axis is sum_l c_l(b) sqrt((2l + 1) / (4 pi)) P_l(cos t) over the even degrees l, where c_l are the m = 0 coefficients of the response in the tournier basis. This is the format MRtrix3’s dwi2response writes, in the units of the signal (not divided by b0). A measurement takes the coefficients of the shell nearest its b-value.

bvals#

b-value of each shell in s/mm^2, shape (n_shells,).

Type:

numpy.ndarray

coefficients#

Coefficients of l = 0, 2, 4, … on each shell, one row per shell, shape (n_shells, n_degrees).

Type:

numpy.ndarray

The white matter response is either built from given tensor eigenvalues or estimated from the data with estimate_wm_rf. Grey matter is added when its diffusivity is given or gm_noddi is set, and CSF when its diffusivity is given. The responses come in the order white matter, grey matter, CSF.

larmor.sd.estimate_csd_rf(volume, gtab, mask, *, num_voxels=300, num_candidates=None, dilate=1, max_iter=10, lmax=10, n_jobs=-1)#

Estimates the white matter response of CSD from the data’s single-fibre voxels.

The response is the signal of a single fibre on the shell CSD fits, the one with the highest b-value. Each iteration deconvolves the candidate voxels, takes the num_voxels whose FODs have the most dominant single peak, and fits a new response to their signals, aligned with their fibres. The iterations stop when those voxels repeat.

Parameters:

  • volume (Volume) – Diffusion-weighted volume, shape (X, Y, Z, N).

  • gtab (GradientTable) – Its gradient table.

  • mask (Volume | ndarray) – The voxels to search (nonzero inside), on the volume’s grid.

  • num_voxels (int) – Number of single-fibre voxels the response is fitted to. Defaults to 300.

  • num_candidates (int | None) – Number of best voxels the next iteration starts from, before growing. Defaults to None, which gives 10 * num_voxels.

  • dilate (int) – Voxels the candidates are grown by (6-connected) each iteration. Defaults to 1.

  • max_iter (int) – Maximum number of iterations, at least 2. Defaults to 10.

  • lmax (int) – Highest degree of the response, even. Defaults to 10.

  • n_jobs (int) – Number of threads; -1 uses every core. Defaults to -1.

Returns:

SingleFibreRF – The response on the highest shell, in the units of the signal, and the voxels it was fitted to.

Raises:

ValueError – If a setting is out of range, or the data have no diffusion-weighted shell.

Return type:

SingleFibreRF

larmor.sd.estimate_wm_rf(volume, gtab, mask)#

Estimates the white matter response from the voxels with FA > 0.7.

In every voxel of the mask whose signal is positive and finite, a tensor is fitted by iterated weighted least squares, with an isotropic kurtosis term when the data has at least two shells above b = 500. The response’s eigenvalues are the medians over the voxels with FA > 0.7, the second and third then averaged so that the response is axially symmetric. Its kurtosis is the mean of the voxel kurtosis values that lie in (0, 4).

Parameters:

  • volume (Volume) – Diffusion-weighted volume, shape (X, Y, Z, N).

  • gtab (GradientTable) – Its gradient table.

  • mask (Volume | ndarray) – Voxels to consider (nonzero inside), on the volume’s grid.

Returns:

AnisotropicRF – Eigenvalues [l1, l23, l23] in mm^2/s and the mean kurtosis; the kurtosis is 0 with fewer than two shells above b = 500.

Raises:

ValueError – If the mask does not match the volume, or no usable voxel in it has FA > 0.7.

Return type:

AnisotropicRF

References

Adapted from MRIToolkit’s Eigenval_IsoK_WM_FromData.

larmor.sd.find_peaks(coeffs, mask=None, *, basis='tournier', num_peaks=None, relative_threshold=0.1, threshold=0.0, chunk_size=10000, n_jobs=-1)#

Extracts the peaks of FODs.

The maxima of the FOD’s amplitude are found by climbing from the vertices of an icosphere, and peaks closer than 0.99 in |cos| are merged. Maxima with an amplitude of 0 or below are dropped, as are those under threshold and those under relative_threshold times the largest peak.

An asymmetric FOD (all SH degrees, recognised by the number of coefficients) is searched the same way, but a peak and its opposite are two peaks, merged only when closer than 0.99 in signed cos, and peaks keep their sign. A straight fibre then gives two peaks, one per lobe.

Parameters:

  • coeffs (NDArray[floating]) – FOD coefficients, shape (…, C), the even degrees of a symmetric FOD or all degrees of an asymmetric one.

  • mask (NDArray[bool] | None) – Voxels to search, shape (…); the other voxels are NaN. Defaults to None, every voxel.

  • basis (str) – SH basis of the FODs. Defaults to “tournier”.

  • num_peaks (int | None) – Number of peaks to extract. Defaults to None, 3 for a symmetric FOD and 6 for an asymmetric one, where each fibre is two peaks.

  • relative_threshold (float) – Fraction of the largest peak below which a peak is dropped. Defaults to 0.1. The FODs of SDModel (GRL and mFOD) need 0.2, which their SDFit.peak_relative_threshold gives.

  • threshold (float) – Amplitude below which a peak is dropped. Defaults to 0.0.

  • chunk_size (int) – Number of voxels whose amplitudes on the icosphere are held in memory at once. Defaults to 10_000.

  • n_jobs (int) – Number of threads, at most the number of cores; -1 uses every core. Defaults to -1.

Returns:

Peaks – The peaks extracted.

Raises:

ValueError – If num_peaks or chunk_size is below 1, if n_jobs is 0 or below -1, if relative_threshold is not between 0 and 1, if mask does not have the shape of coeffs without its last axis, if the coefficient count fits no SH layout or convert_sh_basis refuses the basis, or if lmax is above 20.

Return type:

Peaks

larmor.sd.read_mritoolkit_fod(source, reference, *, variable=None, lmax=8)#

Reads the result of an MRIToolkit GRL or mFOD fit from a MATLAB file.

The result is the struct that MRTTrack’s PerformDeconv returns, with the fields FOD, fractions and RSS, saved in a mat file. It stores each FOD as 300 amplitudes on a fixed set of directions, which are fitted with SH up to lmax in world coordinates. The FODs are scaled as Larmor’s (300 / (4 pi) times the amplitudes), so they compare with Larmor’s own fits of the same data. MRIToolkit’s exports multiply by its kernel’s scale instead, which the file does not store, so the two differ by one factor.

  • variable (str | None) – The struct’s name in the file. Defaults to None, the only struct variable with a field FOD.

  • lmax (int) – The highest SH degree of the FODs, even. Defaults to 8.

Returns:

MRIToolkitFOD – The FODs, the fractions and the residuals on the reference grid.

Raises:

ValueError – If the file has no such struct, or its arrays do not fit the reference grid.

Return type:

MRIToolkitFOD
