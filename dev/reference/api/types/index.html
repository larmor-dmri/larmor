larmor.types#

The core data types, such as volumes, gradient tables, tractograms and surfaces.

Volumes, tractograms and surfaces are in world coordinates (RAS+) in mm.

GradientTable

The diffusion weighting of each volume of a DWI, in the order of the volumes.

Grid

The voxel grid of an image, with its shape and where its voxels are in the world.

Label

One entry of a lookup table, with a label's name and colour.

Surface

A triangle mesh in world coordinates, with named values per vertex.

Tractogram

A set of streamlines, stored as one flat array of points and their offsets.

Volume

An image on a voxel grid, such as a scan, a DWI series or a computed map.
class larmor.types.GradientTable(bvals, bvecs, b0_threshold=50.0, shell_epsilon=80.0)#

The diffusion weighting of each volume of a DWI, in the order of the volumes.

On construction each b-value is scaled by the squared length of its vector, and each vector is scaled to unit length, so a vector of length 0.5 at b = 2800 becomes a unit vector at b = 700. A volume whose scaled b-value falls to b0_threshold or below then counts as a b0, with a warning. The caller’s arrays are copied, not changed.

The checks run only on construction: change a table through flip and permute, not by assigning its fields.

The b-values must be in s/mm^2, or the b0 threshold and the shells are wrong.

Parameters:

  • bvals (ndarray) – (N,) b-values in s/mm^2.

  • bvecs (ndarray) – (N, 3) gradient directions in world coordinates (RAS+). A row of NaN means no direction, like (0, 0, 0).

  • b0_threshold (float) – b-values at or below this, in s/mm^2, count as b0. Defaults to 50.0.

  • shell_epsilon (float) – A gap larger than this between sorted b-values, in s/mm^2, starts a new shell. Defaults to 80.0.

Raises:

ValueError – If the table is empty, the shapes are not (N,) and (N, 3), a b-value is negative, NaN or infinite, a vector has an infinite component, or a volume above b0_threshold has no direction or a vector shorter than 0.1.

property b0_mask: ndarray#

Marks the b0 volumes, whose b-value is at or below b0_threshold.

Returns:

np.ndarray – (N,) bool.

property b_matrix: ndarray#

The six distinct elements of b * g g^T for each volume.

The order is (gx^2, 2 gx gy, 2 gx gz, gy^2, 2 gy gz, gz^2) times b, with the factor 2 of the off-diagonal elements included.

Returns:

np.ndarray – (N, 6) in s/mm^2.

property shells: ndarray#

The b-value of each shell (the mean of its volumes), ascending.

Returns:

np.ndarray – (K,) in s/mm^2; empty when every volume is a b0.

count_shells(*, above=0.0)#

Returns the number of shells, as shells groups them, above a b-value.

b0s never count.

Parameters:

above (float) – Count only the shells whose b-value is above this, in s/mm^2. Defaults to 0, every shell.

Returns:

int – The number of shells.

Return type:

int

property shell_index: ndarray#

The index of each volume in shells, or -1 for a b0.

The b-values of the weighted volumes are sorted, and a gap larger than shell_epsilon between neighbours starts a new shell.

Returns:

np.ndarray – (N,) int.

flip(axis)#

Negates one component of every direction, in place.

Corrects a table that is wrong for its data, such as a y sign reversed by the scanner export. Reorienting a volume never needs it.

Parameters:

axis (int) – The world axis to negate, 0 (x), 1 (y) or 2 (z).

Raises:

ValueError – If axis is not 0, 1 or 2.

permute(order)#

Reorders the components of every direction, in place.

New component j is old component order[j]. Like flip, it corrects a wrong table; reorienting a volume never needs it.

Parameters:

order (tuple[int, int, int]) – A permutation of (0, 1, 2).

Raises:

ValueError – If order is not a permutation of (0, 1, 2).

matches(other, *, atol=0.001)#

Checks whether two grids are the same voxels in the world.

Grids that differ only in the order and direction of their axes, such as a volume and the same volume reoriented, match.

Parameters:

  • other (Grid) – The grid to compare against.

  • atol (float) – Tolerance on the affines, in mm. Defaults to 1e-3, because TRK files store their affine in float32.

Returns:

True if other is this grid with its axes permuted and flipped – same shape after the permutation, and affines equal within atol.

Return type:

bool

class larmor.types.Surface(vertices, faces, vertex_data=<factory>, reference=None)#

A triangle mesh in world coordinates, with named values per vertex.

Surfaces compare by identity (== is is); compare the arrays to compare contents.

Parameters:

  • vertices (ndarray) – The vertices (V, 3) in world coordinates (RAS+) in mm, stored as float32.

  • faces (ndarray) – The vertex indices of each triangle (F, 3), counter-clockwise seen from outside so that normals point out, stored as uint32.

  • vertex_data (dict[str, ndarray]) – Named values per vertex, each with first axis V, such as “curv” or “thickness”. Empty by default.

  • reference (Grid | None) – The voxel grid of the volume the surface was made on, if known. Defaults to None.

Raises:

ValueError – If vertices is not (V, 3) or faces is not (F, 3), the faces are not integers or an index is outside [0, V), or a vertex_data value does not have V entries along its first axis.

property num_vertices: int#

The number of vertices, V.

property num_faces: int#

The number of faces, F.

class larmor.types.Tractogram(points, offsets, point_data=<factory>, streamline_data=<factory>, reference=None)#

A set of streamlines, stored as one flat array of points and their offsets.

Streamline s is points[offsets[s]:offsets[s + 1]]. Index a tractogram with an integer to get one streamline’s points, or with a slice, a list or array of indices, or a boolean mask to get a new tractogram with those streamlines. Tractograms compare by identity (== is is); compare the arrays to compare contents.

Parameters:

  • points (ndarray) – The (P, 3) points of all streamlines, in world coordinates (RAS+) in mm, stored as float32.

  • offsets (ndarray) – The (S + 1,) index where each streamline starts, with P last, stored as int64.

  • point_data (dict[str, ndarray]) – Named values per point, each with first axis P, such as an FA sampled along the streamlines. Empty by default.

  • streamline_data (dict[str, ndarray]) – Named values per streamline, each with first axis S, such as a length or a cluster label. Empty by default.

  • reference (Grid | None) – The voxel grid of the image the tractogram was made on, if known. Defaults to None.

Raises:

ValueError – If points is not (P, 3), offsets are not integers that start at 0, never decrease and end at P, or a point_data or streamline_data value does not have P or S entries along its first axis.

property num_streamlines: int#

The number of streamlines, S.

property num_points: int#

The number of points of all streamlines together, P.

class larmor.types.Volume(data, affine, slope=1.0, intercept=0.0, xform_codes=(1, 1))#

An image on a voxel grid, such as a scan, a DWI series or a computed map.

A volume holds the stored values, the affine that places its voxels in the world, and the scaling that turns stored values into real ones.

data and affine are read only. The affine is copied but the data is not, so the caller must not change the array it passed in. The checks run only on construction, so assigning new values to the fields afterwards is not supported. Volumes compare by identity (== is is).

Parameters:

  • data (ndarray) – The stored values, unscaled, as (X, Y, Z) or (X, Y, Z, N), where N is the series, such as the DWI volumes or FOD coefficients.

  • affine (ndarray) – The (4, 4) matrix from voxel indices to world coordinates (RAS+) in mm, with last row [0, 0, 0, 1].

  • slope (float) – Scaling, value = data * slope + intercept. Defaults to 1.0; 0, NaN or infinity means no scaling.

  • intercept (float) – Scaling offset. Defaults to 0.0.

  • xform_codes (tuple[int, int]) – The NIfTI sform and qform codes, which name the space the affine maps to (1 scanner, 2 aligned to another image, 3 Talairach, 4 MNI 152, 5 another template). Defaults to (1, 1).

Raises:

ValueError – If data is not 3D or 4D, affine is not a finite 4x4 matrix with last row [0, 0, 0, 1] and non-zero axes, or the slope is used but the intercept is not finite.

property voxel_sizes: ndarray#

The voxel size along each voxel axis, as a (3,) array in mm.

property orientation: tuple[str, str, str]#

Closest RAS+ direction of each voxel axis, such as (“R”, “A”, “S”).

property grid: Grid#

The volume’s voxel grid, with the spatial shape (X, Y, Z) and the affine.

as_float(*, dtype=<class 'numpy.float32'>)#

Returns the scaled values, data * slope + intercept, as a float array.

When the data already has dtype and there is no scaling, this returns data itself, read only. The scaling can overflow in a small dtype.

Parameters:

dtype (DTypeLike) – A floating-point type. Defaults to float32.

Returns:

The scaled values, with the shape of data.

Raises:

ValueError – If dtype is not a floating-point type, or if the data is complex.

Return type:

ndarray

order (tuple[int, int, int]) – A permutation of (0, 1, 2); new axis j is old axis order[j].

to_orientation(codes)#

Reorients the volume in place to the given orientation, such as “RAS”.

Only permutes and flips the axes, without resampling, so every voxel keeps its world position.

Parameters:

codes (str | Sequence[str]) – The orientation to reach, with one of R/L, A/P and S/I each.

Raises:

ValueError – If codes is not a valid orientation.
