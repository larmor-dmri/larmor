class larmor.io.MRIToolkitFit(dt, kt, dwi, gradients, mask, maps=<factory>)#

A DTI or DKI fit read from MRIToolkit’s mat file, in world coordinates.

dt#

Diffusion tensor, (X, Y, Z, 6) float32, in the element order of DTIFit.dt, in mm^2/s; 0 outside the mask.

Kurtosis tensor, (X, Y, Z, 15) float32, in the element order of DKIFit.kt; None for a DTI fit.

Type:

The diffusion-weighted data, (X, Y, Z, N), in the file’s volume order (sorted by b-value) and type.

Type:

larmor.types.volume.Volume

gradients#

The gradient table of dwi, from the file’s b-matrix.

Type:

larmor.types.gradient_table.GradientTable

The fitted voxels (where the file’s tensor is finite), (X, Y, Z) bool.

Type:

larmor.types.volume.Volume

class larmor.io.MatlabFile(path)#

A mat file whose variables can be listed and read one at a time.

Values come back the same for every version of the file. Numeric and logical arrays are numpy arrays with MATLAB’s shape, so a[i, j, k] is MATLAB’s a(i+1, j+1, k+1). Sparse matrices are scipy.sparse.csc_array, a char row is a str and a char matrix a list of its rows, a scalar struct is a dict of its fields, and struct arrays and cell arrays are lists in MATLAB’s linear (column-major) order, their shape given by entries. An empty char is "" and an empty cell or struct is []. MATLAB objects (strings, tables, function handles) cannot be read; reading one raises an error naming its class.

A variable is read from the file only when it is first read or listed.

Parameters:

path (str | Path) – The mat file.

property names: list[str]#

The names of the file’s variables, in the file’s order.

entries(recursive=True)#

Lists the variables with their shape and class, without reading their data.

Parameters:

recursive (bool) – If True, also list the fields of structs and the elements of cells and struct arrays with at most 100 elements, after the entry that holds them. Defaults to True.

Returns:

The entries, in the file’s order.

Return type:

list[MatlabEntry]

entry(path)#

Returns the shape and class of the value at a path, without its data.

Parameters:

Return type:

MatlabEntry

larmor.io.iter_tractogram(path, *, batch_size=10000, reference=None)#

Reads a tractogram batch by batch, for files too large to hold in memory.

The streamlines are handed out in order, batch_size at a time, and a streamline is never split between batches. Joined in order, the batches are the tractogram load_tractogram returns, and each batch has its point_data, streamline_data and reference. A file without streamlines gives one empty batch.

Parameters:

  • path (str | Path) – An uncompressed tck or trk file.

  • batch_size (int) – The most streamlines per batch; every batch but the last has exactly this many.

  • reference (Grid | None) – As for load_tractogram.

Returns:

An iterator over the batches.

Raises:

ValueError – At the call, if the file is not tck or trk, is compressed, or batch_size is less than 1. While iterating, if the file cannot be read as its format.

Return type:

Iterator[Tractogram]

larmor.io.load_dwi(path, bvals=None, bvecs=None, *, frame='fsl')#

Loads a diffusion-weighted volume and its gradient table, ready for fitting.

A MIF file can store the gradient table in its header (dw_scheme), and then no other file is needed. A NIfTI file, or a MIF file without a table, needs the bvals and bvecs files, which are never looked for by name. Files given for a MIF file that has a table override the table, with a warning.

The arguments are checked in a fixed order: giving only one of the two files is reported first, then the volume is read, so a missing volume is reported before any problem with the gradients.

Parameters:

  • path (str | Path) – The volume file.

  • bvals (str | Path | None) – The b-values file, or None.

  • bvecs (str | Path | None) – The b-vectors file, in frame, or None. Give both files or neither.

  • frame (Literal['fsl', 'world']) – The frame of the bvecs file: “fsl” (converted with the volume file’s affine) or “world”. A MIF header is always in world coordinates.

Returns:

The volume as read, and its gradient table in world coordinates.

Raises:

  • FileNotFoundError – If the volume or a gradient file does not exist.

  • ValueError – If only one of the two files is given, there is no gradient table (no files, and no table in the header), a file cannot be read, or the table does not have one entry per volume.

Return type:

tuple[Volume, GradientTable]

larmor.io.load_tractogram(path, *, reference=None, on_progress=None, max_streamlines=None, seed=None, space=None)#

Reads a tractogram, in the format given by the file’s extension.

Parameters:

  • path (str | Path) – A tck, trk, vtk or fib file, each also gzipped (gz), or MRIToolkit’s tractography in a mat file.

  • reference (Grid | None) – The grid of the image the tractogram belongs to. A TRK uses it when it has no vox_to_ras and checks it otherwise; TCK and VTK files store no grid, so it becomes the tractogram’s reference as given. A mat file needs it to place its points.

Returns:

The tractogram.

Raises:

  • ValueError – If the extension is not supported, the file cannot be read as that format, max_streamlines is negative, or space is given for a file that is not VTK.

  • ReadCancelledError – If on_progress raises it.

Return type:

Tractogram

larmor.io.read_b_matrix(path, *, ref_path=None)#

Reads a b-matrix file written by write_b_matrix.

The file has one row per volume, b * (gx^2, 2 gx gy, 2 gx gz, gy^2, 2 gy gz, gz^2), in s/mm^2 and world coordinates. B-matrix files from other programs may use another order, units or frame and are read wrongly. A b-matrix does not store the sign of a vector, so each vector is returned with its first non-zero component positive.

Parameters:

  • path (str | Path) – The b-matrix text file.

  • ref_path (str | Path | None) – A volume whose number of volumes the table must match. Defaults to None, which does not check.

Returns:

GradientTable – The b-values (s/mm^2) and unit b-vectors (world coordinates, RAS+) of the file’s rows.

Raises:

ValueError – If the file is missing, empty or not a table of numbers, if it does not have shape (N, 6), or if ref_path is given and is not 4D or its number of volumes differs from N.

Return type:

GradientTable

larmor.io.read_bvals_bvecs(bvals_path, bvecs_path, *, ref_path=None, frame='fsl', grid=None)#

Reads bvals and bvecs files into a gradient table in world coordinates.

The bvecs file holds one direction per volume, in one of two frames. In the “fsl” frame, the convention of FSL’s bvecs files, the directions are along the voxel axes of the image, with x negated when the image’s affine has a positive determinant, so converting them needs the image’s grid. In the “world” frame they are already in world coordinates (RAS+).

Parameters:

  • bvals_path (str | Path) – The bvals file.

  • bvecs_path (str | Path) – The bvecs file, (3, N) or (N, 3).

  • ref_path (str | Path | None) – The image the files belong to. Required for “fsl” unless grid is given; when given, its number of volumes is checked. Defaults to None.

  • frame (Literal['fsl', 'world']) – The frame of the bvecs file. Defaults to “fsl”.

  • grid (Grid | None) – The grid of an image that does not exist as a file, for “fsl” instead of ref_path; the number of volumes is not checked. Defaults to None.

Returns:

GradientTable – The table, with its vectors in world coordinates.

Raises:

ValueError – If the files cannot be read or do not match each other or the image, or “fsl” is given without an image.

Return type:

GradientTable

larmor.io.read_lookup_table(path)#

Reads a lookup table in the FreeSurfer or the MRtrix layout.

Each line holds an index, one or two names and the colour, from 0 to 255, as index name R G B A or index short-name long-name R G B A. The last column is ignored and may be missing. The name kept is the last one, MRtrix’s long name. Lines starting with # are skipped; a later line for an index replaces an earlier one.

Parameters:

Returns:

The labels by their index (the value in the parcellation image).

Raises:

ValueError – If the file cannot be read, a line is not a valid entry, or the file holds no entry; the message names the file and the line.

Return type:

dict[int, Label]
