class larmor.viewer.Viewer(scene=None)#

The viewer’s state and the actions that change it.

Every change to what the viewer shows goes through these methods, whether it comes from the window, from lar bv or from Python, so each behaviour exists once. The window and the drawing follow the scene’s events. A viewer needs no window: view opens one on it, and screenshot draws a view off screen.

Positions are world coordinates in mm, RAS+ (x towards the subject’s right, y anterior, z superior), as in the items’ affines. Categories, views and option names are enums: Category, ViewKind and OptionName.

Parameters:

scene (Scene | None) – The scene to act on; a new empty one if None.

scene#

The items and the view state; read it, change it only through the actions.

Example

>>> viewer = Viewer()
>>> t1 = viewer.load("t1.nii.gz", Category.VOLUMES)
>>> viewer.set(t1.id, OptionName.COLORMAP, Colormap.BONE)
>>> viewer.screenshot(ViewKind.AXIAL, "axial.png")
load(path, category, *, max_streamlines=1000000, transforms=None, reference=None, inverse=False, interpolation=None, format=None, warp_type=None, fsl_input_path=None, fsl_reference_path=None)#

Reads a file into a new item of category, as add adds it.

The file is read before the method returns. Volumes, overlays, FODs and peaks are NIfTI (.nii, .nii.gz) or MRtrix (.mif, .mif.gz, .mih) images; tractograms are TCK, TRK or VTK files; surfaces are GIfTI (.gii) or FreeSurfer surfaces (such as lh.white). For a FreeSurfer surface, lh.curv in its folder is read as its values “curv”, and ../label/lh.cortex.label as its cortex, when they exist.

Parameters:

  • path (str | Path) – The file to read.

  • category (Category) – Where the item goes: Category.VOLUMES, OVERLAYS (masks, maps, parcellations), TRACTOGRAMS, FODS, PEAKS (from lar peaks) or SURFACES.

  • max_streamlines (int | None) – A tractogram with more streamlines keeps a random subset of this size; the same file always gives the same subset. None keeps all. Ignored for images.

  • transforms (list[str] | None) – Bring the item into another space through a registration computed by ANTs, FSL or MRtrix3: its transform files, listed as antsApplyTransforms lists them (an affine, a warp, or a warp and the inverse warp its tool wrote as “warp,inverse_warp”). The files are those that resample an image into the reference space; tractograms and surfaces are brought into the same space. FODs cannot be brought through a registration. None loads the file as it is.

  • reference (str | Path | None) – With transforms: an image of the reference space, whose grid images are resampled onto (needed for images).

  • inverse (bool) – With transforms: go the other way, from the reference space into the space the transforms bring images from.

  • interpolation (str | None) – With transforms, for images: “nearest”, “linear” or “cubic”; None is linear for volumes and nearest for overlays and peaks (whose directions are reoriented).

  • format (str | None) – With transforms: the tool that wrote them, “ants”, “fsl” or “mrtrix”; None guesses from the files (a 4D NIfTI warp can be FSL’s or MRtrix3’s, so it needs format).

  • warp_type (str | None) – With transforms: the warp fields’ type, “deformation” (the default) or “displacement” for MRtrix3, “relative” (the default) or “absolute” for FSL; checked against the fields’ values.

  • fsl_input_path (str | Path | None) – With FSL transforms: the input image of the FLIRT or FNIRT run; defaults to the item when it is an image (to the reference with inverse). Tractograms and surfaces need it.

  • fsl_reference_path (str | Path | None) – With FSL transforms: the run’s reference image; defaults to reference (to the item with inverse). Tractograms and surfaces need it with inverse.

Returns:

The new item; its id names it in the other actions.

Raises:

  • TypeError – If category is not a Category.

  • ValueError – If the file’s extension is not one the category reads, the file cannot be read as that format, an FOD’s number of coefficients fits no SH layout, or the registration cannot be applied (a transform file it cannot read, an image without a reference, an FOD).

  • OSError – If the file cannot be opened.

Return type:

Item

load_matlab(path, preset, *, reference=None, variables=None, tractogram_id=None, max_streamlines=1000000)#

Reads what a MATLAB .mat file holds into new items, as chosen.

The presets read MRIToolkit’s results. TENSOR_FIT (a DTI or DKI fit) adds FA, MD and the eigenvalues as volumes, the first eigenvector as a volume with DTI colours modulated by the FA, and the DWI. FOD_FIT (a GRL or mFOD result) adds its FODs (SH, MRtrix basis) and its fractions and residuals as volumes. TRACTOGRAPHY adds the tracts as a tractogram. MANUAL reads the variables named in variables (paths as in read_matlab, such as “FA”, “DT{1}” or “GRL_Results.FOD”) each as its LoadAs: an image (MRIToolkit’s layout) as a volume, overlay, FODs or peaks; a cell of (N, 3) points as a tractogram; a struct with vertices and faces as a surface; or a cell of one value per point as the values tractogram_id is coloured by. A choice that does not fit its variable’s shape is refused. The file is read before the method returns; sessions reopen the items from the same variables.

Parameters:

  • path (str | Path) – The .mat file.

  • preset (MatlabPreset) – MatlabPreset.TENSOR_FIT, FOD_FIT, TRACTOGRAPHY or MANUAL.

  • reference (str | Path | None) – The grid of files that store none (FOD results, tracts, and images of files without a header): the MRIToolkit fit (.mat) they came from, or a NIfTI or MIF file of its image.

  • variables (dict[str, LoadAs] | None) – For MANUAL, what to read each variable as.

  • tractogram_id (ItemId | None) – The tractogram item coloured by a variable read as LoadAs.POINT_VALUES.

  • max_streamlines (int | None) – As in load.

Returns:

The new items, in the order added.

Raises:

  • ValueError – If the preset does not fit the file, a reference is needed and not given, or a variable cannot be read as chosen.

  • OSError – If a file cannot be opened.

Return type:

list[Item]

add(data, category, *, name=None, source=None, part=None, registration=None)#

Adds an object already in memory, without copying it.

The viewer never changes the object. A volume becomes the main volume, the only visible one. An image starts with its minimum and maximum at its data’s range (scaled by its slope and intercept), and an overlay with its threshold at its minimum. A surface’s colour comes from its name (white yellow, pial red, others light grey), and one with values “curv” is coloured by them. The first item with a grid sets the 2D views’ field of view to that grid’s box and puts the cursor at its centre.

Parameters:

  • data (object) – A Volume for volumes and overlays (3D, or 4D with volumes along the last axis), a Tractogram for tractograms, for FODs a 4D Volume with SH coefficients along the last axis: even degrees only ((lmax + 1)(lmax + 2) / 2 coefficients) or, for an asymmetric FOD, all degrees ((lmax + 1)^2), and for peaks a 4D Volume with x, y and z of each peak’s direction scaled by its amplitude (3 volumes per peak, NaN or 0 where there are fewer peaks), in world coordinates, and for surfaces a Surface.

  • category (Category) – Where the item goes: Category.VOLUMES, OVERLAYS, TRACTOGRAMS, FODS, PEAKS or SURFACES.

  • name (str | None) – The name shown in the scene tree; “Volume 2” and so on if None.

  • source (Path | None) – The file the object came from, if any.

  • part (MatlabPart | None) – What it was read from inside a MATLAB file source, if so; a session reopens it from there.

  • registration (Registration | None) – The registration data was brought through when read from source, if so; a session applies it again.

Returns:

The new item; its id names it in the other actions.

Raises:

  • TypeError – If category is not a Category.

  • ValueError – If data is not of the category’s type, an FOD’s number of coefficients fits no SH layout, or a peaks image is not 4D with a multiple of 3 volumes.

Return type:

Item

save_item(item_id, path)#

Writes an item’s data to a file, which the item then refers to.

The format follows the extension. Tractograms are written as TCK, TRK, VTK or FIB; a TRK is written for the tractogram’s reference grid, else for the grid the 2D views slice along. Volumes, overlays, FODs and peaks are written as NIfTI (.nii, .nii.gz) or MIF (.mif, .mif.gz, .mih). Afterwards the item refers to the new file, so a session saved later reopens it from there, also when it was added without a file. A tractogram read as a random subset of a larger file is written as that subset. Surfaces cannot be saved.

Parameters:

  • item_id (ItemId) – The item to save.

  • path (str | Path) – The file to write; an existing file is replaced.

Returns:

The item, now referring to the file.

Raises:

  • ValueError – If there is no item with that id, it is a surface, or the extension is not one its category writes.

  • OSError – If the file cannot be written.

Return type:

Item

Example

>>> viewer.save_item(bundle.id, "bundle.tck")
replace_data(item_id, data)#

Gives an item new data, keeping its id, options and place in the scene tree.

The data is checked as add checks it, and is not copied. The item then refers to no file: a session leaves it out until it is saved with save_item. Options that depend on the data follow it: an image’s minimum, maximum and threshold keep their place in the data’s range, mapped from the old range onto the new one (min stays at most max); a volume index past the new volumes becomes the last; overlay labels the new data lacks are dropped; a tractogram’s TSF values, one per old point, are dropped; a surface’s values to colour by that the new data lacks are cleared.

Parameters:

  • item_id (ItemId) – The item.

  • data (object) – The new data, of the item’s category’s type.

Raises:

ValueError – If there is no item with that id, or data is not of the category’s type (or, for FODs and peaks, not of their layout).

save_session(path)#

Saves the items and the state of the views to a session file.

The file is JSON (lar.json is the usual extension). It holds each item’s category, name, file (its absolute path and its path from the session file’s folder, so a project folder can be moved) and options, and the view state: cursor, cameras, main volume, selection, maximised view, convention and the overlay and crosshair switches, and the phantom being edited, if any, whose bundles and proxy maps are made again when the session opens. larmor.viewer.view(viewer=None, *, volumes=None, overlays=None, tracts=None, fods=None, peaks=None, surfaces=None, max_streamlines=<larmor.viewer.loading.Default object>, session=None, phantom=None, simulation=None, block=True, mcp=False, mcp_port=None)#

Opens the viewer’s window on files or objects, given by category.

Items appear in the order given. Files are read in the background and appear as each one is read; a file that cannot be read shows a message. Objects are never copied: those given before any file of their category are added at once, the others after the files before them. Calling view again with the same viewer brings its window back and adds to it. A session replaces what the viewer shows; the files and objects given with it are added after its items.

Parameters:

  • viewer (Viewer | None) – The viewer to show; a new one if None.

  • volumes (Sources | None) – Paths or Volume objects; one or a list, like every category.

  • overlays (Sources | None) – Masks, maps or parcellations, as paths or Volume objects.

  • tracts (Sources | None) – Paths or Tractogram objects.

  • fods (Sources | None) – Paths or 4D Volume objects of SH coefficients, in the tournier basis unless their basis option says otherwise.

  • peaks (Sources | None) – Paths or 4D Volume objects as lar peaks writes them, with 3 volumes per peak (its direction scaled by its amplitude).

  • surfaces (Sources | None) – GIfTI (.gii) or FreeSurfer files (such as lh.white), or Surface objects. A FreeSurfer surface’s curvature (lh.curv in its folder) and cortex label (../label/lh.cortex.label) are read with it when they exist.

  • max_streamlines (int | None | Default) – A tractogram file given here with more streamlines is reduced to a random subset of this size when read; the same file always gives the same subset. None keeps all. If not given, the read limit of the Settings panel (1,000,000 unless changed), which files opened later from the window use too. Objects are never reduced.

  • session (str | PathLike[str] | None) – A session file saved from the viewer (File > Save Session or Viewer.save_session). Its files are read in the background, then its options and views are restored. Missing files are reported in a message box, and the rest still opens.

  • phantom (str | PathLike[str] | None) – A phantom file to open in the Simulate workspace, its bundles drawn in the background.

  • simulation (str | PathLike[str] | None) – A simulation folder (from lar simulate or Run in the Simulate workspace), whose phantom opens in the Simulate workspace and whose DWI, tissue masks and ground-truth peaks open as items.

  • block (bool) – Wait until the window is closed. With False, return at once: in IPython or Jupyter, run %gui qt first so the window stays live; in a script, call wait to let the files load.

  • mcp (bool) – Serve the viewer’s actions to agents over MCP, at http://127.0.0.1:<port>/mcp; the URL and the token that requests need are printed. Tool calls run only while Qt’s events run, that is while the window blocks or with %gui qt.

  • mcp_port (int | None) – The port for mcp, which it implies; the port in the Settings window (8765 unless changed) if None. If the port is taken, a message is printed and the window opens without the server.

Returns:

The viewer, whose actions change what the window shows.

Raises:

  • ViewerUnavailableError – If the viewer cannot start on this machine.

  • ValueError – If an object is not of its category’s type, an FOD’s number of coefficients fits no SH layout, a peaks object does not hold 3 volumes per peak, max_streamlines is negative, mcp_port is not between 1024 and 65535, simulation is not a simulation folder, or both phantom and simulation are given.

  • SessionError – If session is not a session file this version reads.

  • FileNotFoundError – If the phantom file does not exist.

  • OSError – If the session file cannot be read.

Waits until the files given to view or opened in the window are loaded.

Needed after view(..., block=False) in a script, where nothing else runs Qt’s events; in IPython or Jupyter with %gui qt, files load on their own.

Parameters:

  • viewer (Viewer) – The viewer whose window loads the files.

  • timeout (float | None) – The longest wait in seconds; None waits as long as it takes.
