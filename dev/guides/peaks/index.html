Peaks#

The peaks of an FOD are its local maxima, which give the directions of the fibres in a voxel, each with an amplitude. find_peaks() finds them from the FOD’s SH coefficients, sorts them largest first, and drops those far smaller than the largest. Conventions gives the SH bases and the layout of the peaks image.

The data on this page

The examples on this page run on a small synthetic FOD image, which the code below writes to the current folder. fod.nii.gz holds SH coefficients up to degree 8 in the tournier basis, and mask.nii.gz covers the voxels of its two bundles. The image has 20 x 20 x 4 voxels of 2 mm. One bundle runs along x and one along y, and where they cross the FOD has both lobes. To work on your own data, use your files instead.

import numpy as np

from larmor.io import save_volume
from larmor.sd import fit_sh
from larmor.types import Volume

n = 600
z = 1 - (2 * np.arange(n) + 1) / n
azimuth = np.pi * (3 - np.sqrt(5)) * np.arange(n)
radius = np.sqrt(1 - z**2)
sphere = np.stack([radius * np.cos(azimuth), radius * np.sin(azimuth), z], axis=1)


def fod(*fibres):
    """SH coefficients of a narrow lobe along each fibre."""
    cosines = sphere @ np.array(fibres).T
    return fit_sh(np.exp(-8 * (1 - cosines**2)).sum(axis=1), sphere, lmax=8)


x, y = np.eye(3)[0], np.eye(3)[1]
along_x = np.zeros((20, 20, 4), bool)
along_x[:, 8:12] = True
along_y = np.zeros((20, 20, 4), bool)
along_y[8:12, :] = True
coeffs = np.zeros((20, 20, 4, 45), np.float32)
coeffs[along_x] = fod(x)
coeffs[along_y] = fod(y)
coeffs[along_x & along_y] = fod(x, y)

affine = np.diag([2.0, 2.0, 2.0, 1.0])
save_volume(Volume(coeffs, affine), "fod.nii.gz")
save_volume(Volume((along_x | along_y).astype(np.uint8), affine), "mask.nii.gz")

Finding the peaks#

import numpy as np

from larmor.io import load_volume, save_volume
from larmor.sd import find_peaks

fod = load_volume("fod.nii.gz")
mask = load_volume("mask.nii.gz").data > 0
peaks = find_peaks(fod.data, mask=mask, num_peaks=3, relative_threshold=0.1)

crossing = np.isfinite(peaks.amplitudes[10, 10, 0])
print(np.round(peaks.directions[10, 10, 0][crossing], 2))

vectors = peaks.directions * peaks.amplitudes[..., None]
save_volume(fod.with_data(vectors.reshape(*fod.data.shape[:3], -1)), "peaks.nii.gz")

The result, a Peaks, holds the unit directions, of shape (X, Y, Z, P, 3), and their amplitudes, of shape (X, Y, Z, P), largest first. Where a voxel has fewer than P peaks, the remaining entries are NaN, and so are all entries outside the mask. The last two lines write the same peaks image as lar peaks.

lar peaks fod.nii.gz peaks.nii.gz --mask mask.nii.gz --num 3 --relative-threshold 0.1

The peaks image has 3 volumes per peak, largest peak first. They hold the x, y and z of the peak’s direction scaled by its amplitude, in world coordinates, and are NaN where a voxel has fewer peaks.

Options#

  • Number of peaks. 3 by default (num_peaks, --num), or 6 for an asymmetric FOD.

  • Thresholds. A peak is dropped when it is below relative_threshold times the voxel’s largest peak, or below the absolute threshold (0 by default), and so is any maximum with an amplitude of 0 or below. The right relative threshold depends on the method that made the FOD. CSD and MSMT-CSD FODs use 0.1, the default of find_peaks. GRL and mFOD FODs need 0.2, because they show small side lobes that would otherwise be reported as fibres (FODs explains why); their fit gives this value as fit.peak_relative_threshold. lar peaks cannot tell from the file which method made the FOD, so you say it with --fod-method. Its default is GRL, as for lar fod, which gives 0.2, while CSD and MSMT-CSD give 0.1. --relative-threshold overrides both.

  • Basis. basis (--basis) gives the FOD’s SH basis, "tournier" by default; see FODs.

  • Symmetric and asymmetric FODs. A symmetric FOD, with even degrees only, has a lobe at both ends of a fibre, so each fibre gives one peak, pointing up (z >= 0). An asymmetric FOD has all degrees, and is recognised by its number of coefficients. In an asymmetric FOD, a peak and its opposite are separate peaks that keep their sign, so a straight fibre gives two.

  • Close fibres. Where two fibres cross at a small angle, their lobes merge into one peak.

Viewing the peaks#

lar bv -p peaks.nii.gz -f fod.nii.gz

The viewer draws each peak as a line through its voxel, over the FOD glyphs.
