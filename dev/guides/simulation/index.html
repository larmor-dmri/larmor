Simulating phantoms#

Simulated images with a known ground truth let you test a method against the answer it should give. Larmor simulates them from a phantom, an object to scan made of tissues that fibre bundles and tissue maps place on a voxel grid. Each tissue is a sum of compartments, such as a stick for the water inside axons or a ball for free water, each with its own diffusion model. simulate() turns a phantom and a scan protocol into diffusion-weighted images, and keeps the ground truth: how much of each voxel each tissue and bundle fills, and where the fibres point. Simulating diffusion MRI describes what is computed and what is not.

For a first run with no code, see the quick start.

Building a phantom#

The phantom below is one straight bundle on a grid of 24 x 24 x 24 voxels of 1 mm. The bundle’s BundleGeometry is a smooth curve through control points in world coordinates (mm), with num_streamlines streamlines spread over a disc of the given radius around it, and its seed makes the streamlines the same on every run. A phantom has the tissues WM, GM and CSF by default, and a bundle is filled with WM unless you name another tissue.

import numpy as np

from larmor.simulation import (
    Bundle,
    BundleGeometry,
    Phantom,
    Protocol,
    create_gradient_table,
    write_phantom,
)
from larmor.types import Grid

grid = Grid((24, 24, 24), np.eye(4))
line = BundleGeometry(
    np.array([[3.0, 12.0, 12.0], [21.0, 12.0, 12.0]]),
    num_streamlines=300,
    radius=2.5,
    seed=1,
)
phantom = Phantom(grid, bundles=(Bundle(line),))

gradients = create_gradient_table([(1000, 32)], num_b0=1, seed=0)
protocol = Protocol(gradients, 15.0, 30.0, 80.0, 3000.0)
write_phantom(phantom, "straight.phantom.json", protocol=protocol)

The protocol holds the gradient table and the timings, which here are the pulse duration delta (15 ms), the time between the pulses Delta (30 ms), the echo time (80 ms) and the repetition time (3000 ms). create_gradient_table spreads the directions of each shell evenly over the sphere, and a table read from bvals and bvecs files works as well (see Gradient tables).

A phantom has four parts.

  • Tissues. Each tissue has a name, by which bundles and maps refer to it. The following functions make the predefined tissues, and their arguments set the fractions, diffusivities and relaxation times.

    • standard_model_tissue() makes white matter as a stick and a zeppelin, with optional free water.

    • noddi_tissue() makes white or grey matter in the NODDI model, with Watson-dispersed sticks, a zeppelin whose diffusivities follow the neurite density and dispersion, and free water.

    • sandi_tissue() makes grey matter.

    • csf_tissue() and free_water_tissue() make free water, named CSF and FW.

    A tissue can also be built from Compartment objects of any model, including the cylinder and the dot. The signal of the stick, the zeppelin, the Watson-dispersed sticks and the cylinder depends on a fibre direction, which only a bundle gives, so a tissue with one of these compartments can fill bundles only. Other tissues can also fill tissue maps and the background.

  • Bundles. A bundle’s shape is a BundleGeometry or a tractogram of your own, such as one from load_tractogram. Each streamline stands for a piece of the bundle’s cross-section, so the fraction of a voxel that a bundle fills, its occupancy, follows the length of streamline in the voxel. Where bundles cross and their occupancies add up to more than the voxel, they are scaled down to fit.

  • Tissue maps. A TissueMap is a volume of fractions in [0, 1] on the grid, such as a grey matter probability. The maps share what the bundles leave of each voxel.

  • Background. What is left after the bundles and maps goes to the tissue named by background, or gives no signal when there is none.

The phantom file#

write_phantom stores the grid, the tissues, the bundles (their geometry, or the path of their tractogram), the paths of the tissue maps and the protocol in one JSON file, *.phantom.json, which you can read and edit. A bundle geometry without a seed gets a random one, written to the file, so that the file always gives the same streamlines. read_phantom() reads the file back.

Running a phantom file#

from larmor.simulation import read_phantom, save_simulation, simulate

loaded = read_phantom("straight.phantom.json")
result = simulate(loaded.phantom, loaded.protocol, snr=30, seed=1)
files = save_simulation(result, "sim")
print(files.dwi[0])

result.echoes holds one 4D volume per echo time, with Rician noise when snr is given, and result.noise_free holds the same without noise. result.partition is the ground truth. The noise level is the same in every voxel, with a standard deviation equal to the b = 0 signal of a voxel filled with the noise_reference tissue (“WM” by default), divided by the SNR. The same seed gives the same images on any number of threads (n_jobs).

lar simulate straight.phantom.json sim --snr 30 --seed 1

lar simulate PHANTOM OUTPUT reads the phantom file and the protocol stored in it, simulates, and writes the output folder, which it creates if needed. In place of a file you can give the name of a phantom that ships with Larmor, such as crossing; see the quick start.

The output folder#

The folder is self-contained. It holds the images, the ground truth, and what is needed to simulate again.

File

Holds

dwi.nii.gz, dwi.bval, dwi.bvec

The images and their gradients, the b-vectors in the FSL frame. With several echo times there is one image per echo, dwi_te60ms.nii.gz, and the gradient files are shared

dwi_noise_free.nii.gz

The same without noise; only when there is noise

tissue_fractions.nii.gz

4D, the volume fraction of each voxel that each tissue fills, in the order of the tissues in simulation.json

background_fraction.nii.gz

The volume fraction no tissue fills

free_water_fraction.nii.gz

The volume fraction of each voxel that free water fills, summed over the free-water compartments of all tissues, background included

bundle_fractions.nii.gz

4D, the volume fraction of each voxel that each bundle fills

compartment_fractions.nii.gz

4D, the volume fraction of each voxel that each compartment fills: its tissue’s fraction times its share of the tissue, in the order listed under compartments in simulation.json

signal_fractions.nii.gz

4D, each compartment’s share of the voxel’s signal at b = 0, in the order of compartment_fractions.nii.gz. With several echo times there is one per echo, signal_fractions_te60ms.nii.gz

free_water_signal_fraction.nii.gz

The share of the voxel’s signal at b = 0 that comes from free water; one per echo time, as above

peaks.nii.gz

The true fibre directions, in the layout lar peaks writes (below)

mask_<tissue>.nii.gz

One mask per tissue: the voxels the tissue fills by at least half, background included

mask_bundles.nii.gz

The voxels that the bundles fill by at least half together, so that a crossing of bundles of different tissues is not left out

bundle_<n>.tck

The streamlines of each bundle

tissue_map_<tissue>.nii.gz

A copy of each tissue map of the phantom

phantom.json

The phantom file, with the protocol; its bundles are the geometry with the seed that was used, or the .tck of the folder

simulation.json

The protocol, SNR, noise level, seed, tissue order and the name of every file

The free-water maps count only the free-water compartment, which the free-water, CSF and NODDI presets and the standard model’s optional free water use. A plain ball does not count as free water, whatever its diffusivity.

Compare a fitted model with the signal-fraction maps, not with the volume fractions. The tissue, background, bundle, compartment and free-water maps are volume fractions, the share of the voxel’s volume that a tissue, bundle or compartment fills. A model fitted to the images, such as free-water imaging, NODDI or the standard model, recovers signal fractions instead, in which each compartment is weighted by its proton density and its relaxation. The signal fraction of compartment c is f_c w_c / (sum over the compartments of f w), where f_c is its volume fraction and w_c = PD (1 - exp(-TR / T1)) exp(-TE / T2) is its relaxation weight (with T2* for a gradient echo), so it changes with the echo time. With the default scan (TE 80 ms, TR 3000 ms), for example, the NODDI preset’s free-water volume fraction of 0.05 makes up about 0.11 of the b = 0 signal, since free water has a proton density of 1 and a long T2, while the neurites and the space around them have 0.7 and 69 ms. Use the maps of the echo time of the images that were fitted.

The ground-truth peaks give the true fibre directions, to compare with the peaks of a fit, such as lar fod followed by lar peaks. They are built from the streamlines, not fitted to the images. In each voxel, the streamline directions are grouped, from the largest down, into peaks: each joins the first peak within 20 degrees of it, or else starts a new one. A peak’s direction is the weighted mean of its fibres, and its amplitude is the share of the voxel they fill. Peaks below a tenth of the voxel’s largest are dropped, and a bundle whose tissue has no fibre direction, such as one filled with CSF, gives none. peaks.nii.gz has 3 volumes per peak, largest peak first, which hold the x, y and z of the direction scaled by the amplitude, in world coordinates, and are NaN where a voxel has fewer peaks.

Running phantom.json again with the same seed gives the same images. Without --seed, a seed is drawn and written to simulation.json; give it to --seed to repeat the run.

lar simulate sim/phantom.json again --snr 30 --seed 1

Options of lar simulate#

  • --snr adds noise, and --noise-reference names the tissue it refers to. Without --snr there is no noise.

  • --seed fixes the noise, and the streamlines of bundles that have no seed.

  • --shell B:N replaces the gradients of the file with a shell of N directions at b = B s/mm^2. Repeat it for several shells, and add --num-b0 to set the number of b = 0 volumes. --bvals and --bvecs, with --bvec-frame, read the gradients from files instead, and for these files the frame fsl refers to the axes of the phantom’s grid.

  • --nt sets the number of threads.

  • --force is needed to write into a folder that is not empty; without it, the command stops before simulating. With it, the files listed in the folder’s simulation.json are removed first, so that none is left over from the earlier run, while other files in the folder stay. save_simulation does the same, and refuses a non-empty folder without a simulation.json unless force=True.

The timings of the protocol always come from the phantom file.

The signal of one voxel#

To see where the signal of a voxel comes from, signal_breakdown() splits the noise-free signal of one voxel in one volume into the factors the simulation multiplies. These are each tissue’s share of the voxel, each compartment’s fraction and proton density, the T1 and T2 relaxation, and the diffusion attenuation. It needs the phantom’s voxel partition, which partition_voxels() makes once for all voxels. plot_signal_breakdown() draws the result as three stacked bars.

from larmor.plot import plot_signal_breakdown
from larmor.simulation import partition_voxels, signal_breakdown

partition = partition_voxels(phantom)
breakdown = signal_breakdown(phantom, protocol, partition, (12, 12, 12), 1, snr=30)
for c in breakdown.compartments:
    print(f"{c.label}: {c.no_decay:.3f} -> {c.after_decay:.3f} -> {c.signal:.3f}")
ax = plot_signal_breakdown(breakdown)
ax.figure.savefig("breakdown.png")

breakdown.signal is the voxel’s value in the noise-free image of a run. With snr, the breakdown also gives the noise floor and the mean of the noisy magnitude.

Viewing the result#

lar bv --simulation sim

The viewer opens the images, the tissue masks over them, the bundles’ streamlines and the true peaks. It also opens the phantom in its Phantom panel, where you can change the phantom and run it again, as described in Phantoms.
