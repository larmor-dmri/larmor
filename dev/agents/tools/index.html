Tools#

This page lists the tools the viewer offers an agent, with the descriptions the agent is given. Each tool is one of the viewer’s actions, the same method that the window and Python call, so load here is Viewer.load in Python. The arguments are sent as JSON. An enum is sent as its text ("volumes"), a position as a list of numbers in world coordinates (mm, RAS+), and an item by the id that scene gives it. Paths are on the computer the viewer runs on.

add_box(centre=None, size=None, role=None, name=None, apply=False)

Adds a box region, its edges along the world axes.

As add_sphere; a point is inside the box when it is at most half the size from the centre along each of x, y and z.

Parameters:

  • centre – Its centre (x, y, z), world mm; the cursor if None.

  • size – Its edges’ lengths along x, y and z, mm, each positive; the last box’s size (10 mm a side at first) if None.

  • role – RegionRole.INCLUDE, EXCLUDE, WITHIN or None, as for a sphere.

  • name – Its name in the scene tree; “Box 1” and so on if None.

  • apply – Apply it to every tractogram in the scene.

Returns:

The region’s id.

Raises:

  • TypeError – If role is not a RegionRole or None.

  • ValueError – If centre is not three finite numbers.

  • OptionError – If size is not three positive numbers.

add_bundle_point(position)

Adds a control point at the end of the bundle being drawn.

The bundle is drawn again from its points, once per frame in a window.

Parameters:

position – The point (x, y, z), world mm.

A point at the place of the last one is not added again.

Raises:

ValueError – If no bundle is being drawn, or position is not three finite numbers inside the phantom’s grid box.

add_bundle_stroke(points)

Adds the control points of a stroke, as a freehand drag draws one.

The stroke becomes the fewest points evenly spaced along it, at most 24 and always its first and last, whose centreline stays within about one voxel of the views’ grid of the stroke; those inside the phantom’s grid box are added at the end of the bundle being drawn.

Parameters:

points – The stroke’s points (x, y, z), world mm, in order.

Returns:

The number of control points added.

Raises:

ValueError – If no bundle is being drawn, a point is not three finite numbers, or no point of the stroke is inside the grid box.

add_label_region(parcellation_id, mode='from_a_to_b', labels_a=[], labels_b=[], end_radius=4.0, role=None, name=None, apply=False)

Adds a label region: sets of a parcellation’s labels.

From A to B keeps the streamlines with one end in set A and the other in set B, the ends assigned to labels as endpoint_nodes assigns them, with end_radius as its radius; an empty set takes any end. Stay within keeps the streamlines whose points all lie in the voxels of set A (with the tractogram’s ends only, only the first and last points), as stays_within with their mask. The include and within roles keep these streamlines and exclude drops them. With no labels the region keeps every streamline. The region is removed with its parcellation.

Parameters:

  • parcellation_id – The parcellation: a volume or an overlay of one volume.

  • mode – LabelMode.FROM_A_TO_B or STAY_WITHIN.

  • labels_a – Set A’s labels, each 1 or more.

  • labels_b – Set B’s labels, each 1 or more.

  • end_radius – How far from an end a labelled voxel’s centre may be, mm; 0 uses only the voxel the end is in.

  • role – RegionRole.INCLUDE, EXCLUDE, WITHIN or None, as for a sphere.

  • name – Its name in the scene tree; “Labels 1” and so on if None.

  • apply – Apply it to every tractogram in the scene.

Returns:

The region’s id.

Raises:

  • TypeError – If mode or role is not its enum.

  • ValueError – If there is no item with that id.

  • OptionError – If the item is not an image of one volume, a label is below 1, or the radius is outside 0 to 50 mm.

add_mask(mask_id, role=None, name=None, apply=False)

Adds a mask region: the voxels of an image whose value is not zero.

A point is inside the mask when it lies in a voxel whose value rounds to a whole number other than 0. The region is removed with its image.

Parameters:

  • mask_id – The image: a volume or an overlay of one volume, on any grid.

  • role – RegionRole.INCLUDE, EXCLUDE, WITHIN or None, as for a sphere.

  • name – Its name in the scene tree; the image’s name and “(mask)” if None.

  • apply – Apply it to every tractogram in the scene.

Returns:

The region’s id.

Raises:

  • TypeError – If role is not a RegionRole or None.

  • ValueError – If there is no item with that id.

  • OptionError – If the item is not an image of one volume.

add_sphere(centre=None, radius=None, role=None, name=None, apply=False)

Adds a sphere region, an item of Category.REGIONS.

A region filters the streamlines of the tractograms it is applied to (apply_region): a point is inside the sphere when it is at most the radius from the centre. The sphere starts in its role’s colour.

Parameters:

  • centre – Its centre (x, y, z), world mm; the cursor if None.

  • radius – Its radius in mm, at least 0.1; the last sphere’s radius (5 mm at first) if None.

  • role – RegionRole.INCLUDE keeps the streamlines that pass through it, EXCLUDE drops them, WITHIN keeps those that stay inside; None takes the regions’ default (set_default), else INCLUDE.

  • name – Its name in the scene tree; “Sphere 1” and so on if None.

  • apply – Apply it to every tractogram in the scene.

Returns:

The region’s id.

Raises:

  • TypeError – If role is not a RegionRole or None.

  • ValueError – If centre is not three finite numbers.

  • OptionError – If the radius is not a number of at least 0.1.

apply_region(tract_id, region_id, applied=True)

Applies a region to a tractogram’s streamlines, or stops applying it.

With the filter on (OptionName.REGION_FILTER, on by default), only the streamlines that pass through every include region applied, through no exclude one, and stay within every within one are drawn. A streamline passes through a region when one of its points is inside it, and stays within it when all are. The subset and the points per streamline then apply to the streamlines kept. One region can filter several tractograms.

Parameters:

  • tract_id – The tractogram.

  • region_id – The region item.

  • applied – Apply it, or stop applying it.

Raises:

  • ValueError – If there is no item with either id.

  • OptionError – If the first item is not a tractogram or the second not a region.

cancel_bundle()

ValueError – If no bundle is being drawn.

Parameters:

Raises:

  • OptionError – If the item is not a tractogram.

click_label(point, remove=False)

Adds the label at a point to the set being edited, or removes it.

This is what a click with the Label region tool does. The set is the one chosen with edit_labels; without one, set A of the selected label region, else of the last label region. With no label region at all, one is added on the selected parcellation (or the topmost overlay shown as labels) and applied to every tractogram.

Parameters:

  • point – The point (x, y, z), world mm.

  • remove – Remove the label instead of adding it.

Returns:

The label, or None if the point is in no label.

Raises:

ValueError – If there is no label region and no parcellation to make one on.

close_detail(detail_id)

Closes a detail window.

Parameters:

detail_id – The detail window.

Raises:

ValueError – If there is no such detail window.

close_phantom()

Closes the phantom: its bundles and proxy maps are removed.

data_choices(item_id, name)

Returns the names an option that names some of an item’s data can take.

For OptionName.COLOUR_BY: the surface’s values per vertex, one number per vertex each, such as “curv” or “thickness”.

Parameters:

  • item_id – The item whose option it is.

  • name – An option that names some of the item’s data.

Returns:

The names, in the data’s order; None, for no data, is always allowed.

Raises:

  • TypeError – If item_id or name is of the wrong type.

  • ValueError – If there is no item with that id.

  • OptionError – If the item has no such option, or it names no data.

edit_bundle(item_id)

Draws a finished bundle again: its points come back into draw mode.

Its item is changed in place, keeping its id and options.

Parameters:

item_id – The bundle’s tractogram item.

Raises:

ValueError – If it is not a drawn bundle of the phantom.

edit_labels(region_id, which='a')

Chooses the label region and set that click_label changes.

Parameters:

  • region_id – A label region.

  • which – LabelSet.A or LabelSet.B.

Raises:

  • TypeError – If which is not a LabelSet.

  • ValueError – If there is no item with that id.

  • OptionError – If the item is not a label region.

export(preset, path, view=None)

Draws one view, or the window’s layout, off screen with an export preset.

The preset sets the size, the scale, the background, the information overlay, the transparency, the 3D camera and the options given to the items while the image is drawn; the scene is as it was afterwards. The preset’s size is the whole image’s, which the window’s layout shares among its views. The shipped presets are “Screen”, “Figure”, “Talk” and “Website”, and the Export sheet saves others in the settings folder.

Parameters:

  • preset – The preset’s name.

  • path – The image file to write; its extension sets the format (.png, .jpg, .tif, …). An existing file is replaced.

  • view – The view to draw, or None for the window’s layout, as in screenshot.

Returns:

The path written.

Raises:

  • ViewerUnavailableError – If the viewer’s dependencies are not installed.

  • TypeError – If view is neither a ViewKind nor None.

  • ValueError – If there is no such preset, the image is larger than the GPU draws, or the extension is not an image format (or is JPEG with a transparent background).

  • OSError – If the file cannot be written.

export_rotation(preset, path, speed=30.0, duration=12.0, fps=30)

Records the 3D view turning, off screen, with an export preset.

The turn starts from the preset’s 3D camera, or from the 3D view’s if the preset has none.

Parameters:

  • preset – The preset’s name, as for export.

  • path – The file to write, .webp or .gif, as in record_rotation.

  • speed – Degrees the scene turns per second.

  • duration – Seconds of video.

  • fps – Frames per second, a whole number; a GIF takes at most 50.

Returns:

The path written.

Raises:

  • ViewerUnavailableError – If the viewer’s dependencies are not installed.

  • TypeError – As for record_rotation.

  • ValueError – If there is no such preset, or as for record_rotation.

  • OSError – If the file cannot be written.

export_views(preset, path)

Draws the three 2D views off screen with an export preset, a file each.

Parameters:

  • preset – The preset’s name, as for export.

  • path – The name the files are made from, as in screenshot_views.

Returns:

The paths written – axial, coronal, sagittal.

Raises:

  • ViewerUnavailableError – If the viewer’s dependencies are not installed.

  • ValueError – As for export.

  • OSError – If a file cannot be written.

load(path, category, max_streamlines=1000000, transforms=None, reference=None, inverse=False, interpolation=None, format=None, warp_type=None, fsl_input_path=None, fsl_reference_path=None)

Reads a file into a new item of category, as add adds it.

The file is read before the method returns. Volumes, overlays, FODs and peaks are NIfTI (.nii, .nii.gz) or MRtrix (.mif, .mif.gz, .mih) images; tractograms are TCK, TRK or VTK files; surfaces are GIfTI (.gii) or FreeSurfer surfaces (such as lh.white). For a FreeSurfer surface, lh.curv in its folder is read as its values “curv”, and ../label/lh.cortex.label as its cortex, when they exist.

Parameters:

  • path – The file to read.

  • category – Where the item goes: Category.VOLUMES, OVERLAYS (masks, maps, parcellations), TRACTOGRAMS, FODS, PEAKS (from lar peaks) or SURFACES.

  • max_streamlines – A tractogram with more streamlines keeps a random subset of this size; the same file always gives the same subset. None keeps all. Ignored for images.

  • transforms – Bring the item into another space through a registration computed by ANTs, FSL or MRtrix3: its transform files, listed as antsApplyTransforms lists them (an affine, a warp, or a warp and the inverse warp its tool wrote as “warp,inverse_warp”). The files are those that resample an image into the reference space; tractograms and surfaces are brought into the same space. FODs cannot be brought through a registration. None loads the file as it is.

  • reference – With transforms: an image of the reference space, whose grid images are resampled onto (needed for images).

  • inverse – With transforms: go the other way, from the reference space into the space the transforms bring images from.

  • interpolation – With transforms, for images: “nearest”, “linear” or “cubic”; None is linear for volumes and nearest for overlays and peaks (whose directions are reoriented).

  • format – With transforms: the tool that wrote them, “ants”, “fsl” or “mrtrix”; None guesses from the files (a 4D NIfTI warp can be FSL’s or MRtrix3’s, so it needs format).

  • warp_type – With transforms: the warp fields’ type, “deformation” (the default) or “displacement” for MRtrix3, “relative” (the default) or “absolute” for FSL; checked against the fields’ values.

  • fsl_input_path – With FSL transforms: the input image of the FLIRT or FNIRT run; defaults to the item when it is an image (to the reference with inverse). Tractograms and surfaces need it.

  • fsl_reference_path – With FSL transforms: the run’s reference image; defaults to reference (to the item with inverse). Tractograms and surfaces need it with inverse.

Returns:

The new item; its id names it in the other actions.

Raises:

  • TypeError – If category is not a Category.

  • ValueError – If the file’s extension is not one the category reads, the file cannot be read as that format, an FOD’s number of coefficients fits no SH layout, or the registration cannot be applied (a transform file it cannot read, an image without a reference, an FOD).

  • OSError – If the file cannot be opened.

load_matlab(path, preset, reference=None, variables=None, tractogram_id=None, max_streamlines=1000000)

Reads what a MATLAB .mat file holds into new items, as chosen.

The presets read MRIToolkit’s results. TENSOR_FIT (a DTI or DKI fit) adds FA, MD and the eigenvalues as volumes, the first eigenvector as a volume with DTI colours modulated by the FA, and the DWI. FOD_FIT (a GRL or mFOD result) adds its FODs (SH, MRtrix basis) and its fractions and residuals as volumes. TRACTOGRAPHY adds the tracts as a tractogram. MANUAL reads the variables named in variables (paths as in read_matlab, such as “FA”, “DT{1}” or “GRL_Results.FOD”) each as its LoadAs: an image (MRIToolkit’s layout) as a volume, overlay, FODs or peaks; a cell of (N, 3) points as a tractogram; a struct with vertices and faces as a surface; or a cell of one value per point as the values tractogram_id is coloured by. A choice that does not fit its variable’s shape is refused. The file is read before the method returns; sessions reopen the items from the same variables.

Parameters:

  • path – The .mat file.

  • preset – MatlabPreset.TENSOR_FIT, FOD_FIT, TRACTOGRAPHY or MANUAL.

  • reference – The grid of files that store none (FOD results, tracts, and images of files without a header): the MRIToolkit fit (.mat) they came from, or a NIfTI or MIF file of its image.

  • variables – For MANUAL, what to read each variable as.

  • tractogram_id – The tractogram item coloured by a variable read as LoadAs.POINT_VALUES.

  • max_streamlines – As in load.

Returns:

The new items, in the order added.

Raises:

  • ValueError – If the preset does not fit the file, a reference is needed and not given, or a variable cannot be read as chosen.

  • OSError – If a file cannot be opened.

load_phantom(path)

Opens a phantom file, replacing the phantom open.

Each bundle is drawn once and added as a tractogram item; the tissue maps are added as overlays.

Parameters:

path – A phantom file.

Raises:

  • ValueError – If it is not a phantom file or holds invalid values.

  • OSError – If a file cannot be read.

load_session(path, max_streamlines=1000000)

Replaces the scene with the one a session file holds.

Each file is looked for at its path from the session file’s folder, then at its absolute path, and read before the method returns, as load reads it. A file that is missing or cannot be read, and an option or a view-state field that is no longer allowed, are reported (and logged), and the rest of the session still opens.

Parameters:

  • path – A session file written by save_session.

  • max_streamlines – A tractogram with more streamlines keeps a random subset of this size, as in load; None keeps all.

Returns:

The items opened and the problems met, one sentence each.

Raises:

  • SessionError – If the file is not a session, or was saved by a newer Larmor; the scene is then unchanged.

  • OSError – If the session file cannot be read.

new_phantom(size_mm=[60.0, 60.0, 60.0], voxel_mm=2.0, grid_of=None)

Starts a phantom to simulate, replacing the one open.

A phantom is a voxel grid with named tissues (WM, GM and CSF to start with), bundles drawn in the 2D views (each an ordinary tractogram item) or loaded tractograms used as bundles, tissue maps and a scan. The views are fitted to its grid. The items the old phantom made are removed.

Parameters:

  • size_mm – The grid’s box (x, y, z) in mm, centred on the origin.

  • voxel_mm – The voxel size in mm.

  • grid_of – Use the grid of this loaded image instead of a box.

Raises:

ValueError – If a size is not positive, or grid_of is not an image.

open_detail(view, box)

Opens a detail window: a rectangle of a 2D view, drawn on its own.

The window shows the rectangle’s voxels filling its picture, with the slices drawn without smoothing, FOD glyphs built for the rectangle alone at the window’s own sphere detail (12 at first), and optional voxel edges and scale bar. It follows the crosshair’s slice while linked (set_detail). In the window the detail is shown in its own floating window, and its rectangle is outlined in the view.

Parameters:

  • view – ViewKind.AXIAL, CORONAL or SAGITTAL.

  • box – The rectangle in the voxels of the main volume, or of the first visible FOD when there is none: the lowest index and the size along each of the two voxel axes in the view’s plane, the lower axis first, (i, j, size i, size j). The part inside the grid is kept.

Returns:

The detail window’s id.

Raises:

  • TypeError – If view is not a ViewKind.

  • ValueError – If view is the 3D view, nothing with a grid is loaded, box is not four whole numbers with positive sizes, or it lies outside the grid.

open_regions(path, tract_id=None)

Adds the regions of a regions file, or of a session, to the scene.

The images that mask regions name are opened unless an item already shows the same file. With a tractogram, the regions are applied to it and its region filter is set as the file holds it, so the same tractogram keeps the same streamlines.

Parameters:

  • path – A regions file written by the Dissect workspace’s Save step, or a session file.

  • tract_id – The tractogram to apply the regions to; None applies them to none.

Returns:

The images opened and the problems met, one sentence each.

Raises:

  • SessionError – If the file is not a regions or session file.

  • OSError – If the file cannot be read.

  • OptionError – If tract_id is not a tractogram.

open_simulation(folder)

Opens a simulation folder, its phantom in the phantom editor.

The folder is one lar simulate or Run writes. Its phantom file opens in the phantom editor, replacing the phantom open, with each bundle as a tractogram item referring to the bundle’s streamline file; the DWI opens as a volume, the tissue masks as overlays and the ground-truth fibre directions as peaks.

Parameters:

folder – The simulation folder, holding simulation.json.

Returns:

The items opened – the bundles, the DWI, the masks and the peaks.

Raises:

  • ValueError – If it is not a simulation folder, or its phantom file is not valid.

  • OSError – If a file cannot be read.

readout()

Returns what the crosshair reports, as the 2D views show it.

Returns:

The cursor’s position (mm, RAS+) and, with a main volume, its name, the nearest voxel (i, j, k, with the volume index for a 4D image) and the value there in scaled units, interpolated if the volume is shown interpolated; voxel and value are None outside its grid.

record_rotation(path, size=[800, 800], scale=1.0, speed=30.0, duration=12.0, fps=30, overlay=None, transparent=False)

Records the 3D view turning, off screen, as an animated WebP or GIF.

The scene turns about the screen’s up axis, starting from the 3D view’s camera, which is left as it is: with a window open, its 3D view does not move. The frames are written as they are drawn, except that a GIF keeps every frame in memory until it is written.

Parameters:

  • path – The file to write: .webp or .gif. An existing file is replaced once the video is complete, and kept if it is cancelled.

  • size – The 3D view’s width and height in logical pixels.

  • scale – Pixels per logical pixel in the frames.

  • speed – Degrees the scene turns per second, towards the screen’s right; negative turns it to the left.

  • duration – Seconds of video; the default, at the default speed, is one full turn.

  • fps – Frames per second, a whole number; a GIF takes at most 50. GIF frame times are whole hundredths of a second, so at 30 fps its frames last 30 or 40 ms.

  • overlay – Whether to draw the information overlay; None follows toggle_overlay’s switch.

  • transparent – Whether the background is transparent; needs WebP.

  • on_progress – Called after each frame with the number of frames drawn and their total, for example to show progress; it returns True to go on, or False to cancel.

Returns:

The path written, or None if on_progress cancelled the video.

Raises:

  • ViewerUnavailableError – If the viewer’s dependencies are not installed.

  • TypeError – If overlay or transparent is not a bool, speed or duration is not a real number, or fps is not a whole number.

  • ValueError – If size or scale is not positive, the frames are larger than the GPU draws, the extension is neither .webp nor .gif (or is .gif with a transparent background or fps above 50), speed is not finite, duration is not positive, or fps is not positive.

  • OSError – If the file cannot be written.

save_item(item_id, path)

Writes an item’s data to a file, which the item then refers to.

The format follows the extension. Tractograms are written as TCK, TRK, VTK or FIB; a TRK is written for the tractogram’s reference grid, else for the grid the 2D views slice along. Volumes, overlays, FODs and peaks are written as NIfTI (.nii, .nii.gz) or MIF (.mif, .mif.gz, .mih). Afterwards the item refers to the new file, so a session saved later reopens it from there, also when it was added without a file. A tractogram read as a random subset of a larger file is written as that subset. Surfaces cannot be saved.

Parameters:

  • item_id – The item to save.

  • path – The file to write; an existing file is replaced.

Returns:

The item, now referring to the file.

Raises:

  • ValueError – If there is no item with that id, it is a surface, or the extension is not one its category writes.

  • OSError – If the file cannot be written.

Saves the items and the state of the views to a session file.

The file is JSON (.lar.json is the usual extension). screenshot(view, path, size=[800, 800], scale=1.0, overlay=None, transparent=False)

Draws one view, or all of them, off screen, as the window shows them.

Needs no window and no Qt, only the viewer’s drawing library (pygfx) and a GPU or a software renderer. With a window open, the image is drawn separately, at the given size, and the window is not changed. To draw many images of one scene, an OffscreenRenderer (in larmor.viewer.render.offscreen) is faster: it is set up once.

Parameters:

  • view – The view to draw, or None for the whole window’s layout: the maximised view if there is one, else the four views in the window’s 2 x 2 grid (axial, coronal; sagittal, 3D), with a thin grey line between them.

  • path – The image file to write; its extension sets the format (.png, .jpg, .tif, …). An existing file is replaced.

  • size – Each view’s width and height in logical pixels, the units of the window’s views; text and lines keep their size in them.

  • scale – Pixels per logical pixel in the image, for example 2 for twice the resolution with the same layout.

  • overlay – Whether to draw the information overlay (text, labels and colour bars); None follows toggle_overlay’s switch, which the screenshot leaves as it is.

  • transparent – Whether the background is transparent (an RGBA image) rather than the views’ background colour; needs PNG or TIFF.

Returns:

The path written. The image is RGB, or RGBA if transparent; each view in it is size times scale pixels.

Raises:

  • ViewerUnavailableError – If the viewer’s dependencies are not installed.

  • TypeError – If view is neither a ViewKind nor None, or overlay or transparent is not a bool.

  • ValueError – If size or scale is not positive, the image is larger than the GPU draws, or the extension is not an image format (or is JPEG with a transparent background).

  • OSError – If the file cannot be written.

set(target, name, value)

Changes one option of an item, or of every item of a category.

Showing a volume makes it the main volume and hides the others; setting the Volumes category’s visibility shows or hides the main volume only. A new volume index drops the surface labels its volume does not hold. Minimum, maximum and threshold are in the image’s scaled units. DTI colours need a 4D image with 3 volumes (a direction’s x, y and z), and the image that modulates them must be one of item_choices. A surface’s values to colour by must be one of data_choices; a new one also sets the colormap and range: for “curv” and “sulc” white to black from -0.3 to 0.3, for others the image default over the values’ range. A tractogram’s TSF file (VALUES_FILE) must hold a value per point of its streamlines, and its sampled volume (VALUES_VOLUME) must be one of item_choices; setting either clears the other, colours the tractogram by value and sets the range to the values’ (for a volume, its data’s).

Parameters:

  • target – An item’s id, or a Category to change all its items.

  • name – The option, such as OptionName.COLORMAP.

  • value – The new value, of the option’s type: a bool, a number, a Colormap, a path for a lookup table (”” for the built-in colours) or a TSF file (”” for none), label numbers for SURFACE_LABELS, which must be among the overlay’s labels, or another item’s id (or None) for an option that names an item, such as OptionName.MODULATE or VALUES_VOLUME, or a name (or None) for OptionName.COLOUR_BY. A tractogram’s REGIONS are region items’ ids. A region’s CENTRE is (x, y, z) in world coordinates and its SIZE three lengths, mm; its shape is set when it is added.

Raises:

  • TypeError – If target or name is of the wrong type.

  • OptionError – If the items have no such option, the value is outside the option’s range or choices, the option (such as the volume index) is set per item and target is a category, DTI colours are asked of an image without 3 volumes, the item named is not one the option can name, a surface has no such values, or a TSF file cannot be read or does not match the tractogram.

  • ValueError – If there is no item with that id.
