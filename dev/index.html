Larmor#

A Python library and viewer for simulating and processing diffusion MRI

Whole-brain tractography drawn as tubes, coloured by direction.

FODs fitted on a phantom of the brain simulated from tractography bundles.

The Simulate workspace, which guides a simulation step by step.

The signal of one simulated voxel, split into its factors.

FOD glyphs on a coronal slice, with the round FODs hidden.

Asymmetric FOD glyphs.

FOD peaks drawn as lines, each as long as its amplitude.

DTI colours of the principal direction, modulated by FA.

FA over the T1-like image on a sagittal slice.

Streamlines over a slice of the T1-like image in the 3D view.

These images were drawn by BrainViewer, from the ISMRM 2015 Tractography Challenge data and from a phantom that Larmor simulated from the challenge’s ground-truth bundles, both processed with Larmor.

Data: ISMRM 2015 Tractography Challenge (Maier-Hein et al., Nat Commun 8 (2017) 1349), CC BY 4.0.

Install#

pip install larmor-dmri

uv tool install "larmor-dmri[viewer]"
lar bv --install-launcher

git clone https://github.com/larmor-dmri/larmor.git
cd larmor
uv sync

The Install page explains each of these in more detail, and how to run the viewer on a remote server or without a GPU.

Cite Larmor#

If you use Larmor, please cite it, together with the papers of the methods you used. The Citing page lists them.
