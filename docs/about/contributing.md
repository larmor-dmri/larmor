# Contributing

Larmor is developed on GitHub, in the repository `larmor-dmri/larmor`.

To report a problem or ask a question, open an issue in the repository. For a problem, say what you ran (the
command or the Python code), what you expected, what happened, and which version of Larmor and which operating
system you used.

To propose a change, open an issue first, so that the change can be discussed before work starts, and then a pull
request. The repository's `docs/contributing.md` describes the workflow, the tests and the checks a pull request
must pass, and `docs/style.md` the code style.

Every change comes with tests, and every user-facing feature with an example in the
{doc}`gallery <../gallery/index>`. Contributions are distributed under Larmor's [licence](index.md#licence).
