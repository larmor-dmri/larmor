# Keyboard shortcuts

This page lists every key and mouse control of the viewer, as Help > Shortcuts lists them in the viewer itself.
Ctrl is Cmd on macOS. A key acts on the selected view, which is the view you clicked last, and works only when
that view is one of those listed for the key. Text typed into a panel's field stays in the field, and Tab moves
the keyboard focus between a panel's controls.
