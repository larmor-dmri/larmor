Citing#

Citing Larmor#

If you use Larmor in your work, please cite it, together with the papers of the methods you used, listed below. There is no paper about Larmor yet, so cite the software itself, with the version you used (lar --version prints it). The DOI 10.5281/zenodo.23604584 is that of version 2.0.0. Cite it as follows:

Di Meglio A. Larmor: a Python library and viewer for diffusion MRI, version x.y.z. doi:10.5281/zenodo.23604584

In BibTeX:

@software{larmor,
  author  = {Di Meglio, Antonio},
  title   = {Larmor: a Python library and viewer for diffusion MRI},
  version = {x.y.z},
  year    = {YYYY},
  doi     = {10.5281/zenodo.23604584},
  url     = {https://larmor.org},
}

The same information is in the repository’s CITATION.cff file, which GitHub and reference managers read.

Toolboxes#

The spherical deconvolution methods and their solvers (GRL, mFOD, dRL and L2NNLS) are reimplementations of those in MRIToolkit, by Alberto De Luca (github.com/delucaal/MRIToolkit), and the LASSO solver is based on MRIToolkit’s LASSO method. CSD and the estimate of its response, with their defaults and the response file format, follow MRtrix3’s dwi2fod csd and dwi2response tournier; MSMT-CSD and its tissue responses follow dwi2fod msmt_csd and dwi2response dhollander. Denoising, Gibbs-ringing removal, tractogram editing, track density images and connectomes follow MRtrix3’s dwidenoise, mrdegibbs, tckedit, tckmap and tck2connectome: Tournier JD et al. MRtrix3: A fast, flexible and open software framework for medical image processing and visualisation. NeuroImage 202 (2019) 116137. doi:10.1016/j.neuroimage.2019.116137
